# Metro Haven — your urban escape.

Direct-booking website for Metro Haven's suites (Ebony, Cedar & Willow) at Grass Residences, Quezon City.

- Live site: https://alfonsosantino.github.io/metro_haven/
- Admin dashboard: https://alfonsosantino.github.io/metro_haven/admin/

## Structure
- `index.html` — homepage
- `ebony-suite.html`, `cedar-suite.html`, `willow-suite.html` — suite pages (generated by `build_suites.py`, styles in `css/suite.css`)
- `calendar.html` — availability calendar + Book Now
- `admin/` — booking dashboard (password protected by the backend)
- `js/config.js` — backend URL setting
- `backend/` — Google Apps Script backend + `SETUP.md`
- `bookings.js` — optional manual date blocks (merged with live data)
- `img/` — photos and logos
