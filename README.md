# Metro Haven — your urban escape.

Direct-booking website for Metro Haven's suites (Ebony, Cedar & Willow) at Grass Residences, Quezon City.

Live site: https://alfonsosantino.github.io/metro-haven-website/

## Structure
- `index.html` — the full single-page site (styles and scripts included)
- `img/` — suite photos and logos

## Updating
```
git add .
git commit -m "Describe your change"
git push
```
GitHub Pages republishes automatically within a minute or two.
